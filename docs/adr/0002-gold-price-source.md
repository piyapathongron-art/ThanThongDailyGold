# 2. รับราคาทองคำแท่งจาก thaigold.info และให้ทองรูปพรรณเป็นราคาที่พนักงานกรอกเอง

Date: 2026-07-22

## Status

Accepted

## Context

ป้ายราคาเคยมีแหล่งราคาสองชั้น ทั้งสองชั้นตายพร้อมกัน และวัดผลได้ชัดเจน:

- `classic.goldtraders.or.th` — Cloudflare ตอบ **403** ทดสอบจาก iad1 และ sin1 ได้ผลเดียวกัน
  ส่ง header ครบชุดแบบเบราว์เซอร์จริงก็ยัง 403 การบล็อกอยู่ที่ IP ดาต้าเซ็นเตอร์
- `api.chnwt.dev` — คืน 200 พร้อมราคาว่างทุกช่อง

สาเหตุของชั้นที่สองอ่านได้จากซอร์ส: `api.chnwt.dev` คือ `max180643/thai-gold-api`
ซึ่ง scrape goldtraders ด้วย cheerio และตรวจแค่ `statusCode !== 200` Cloudflare ส่งหน้า
challenge กลับมาด้วย status 200 โค้ดจึงผ่านด่าน แต่ cheerio หา selector ไม่เจอ
ได้ string ว่าง แล้ว `return status: "success"`

ทางเลือกที่พิจารณา:

- **เปิด `max180643/thai-gold-api` เอง** — โค้ดเดียวกัน เว็บเดียวกัน Cloudflare เดียวกัน
  จะช่วยได้ก็ต่อเมื่อโฮสต์บนเน็ตบ้านในไทย ซึ่งแปลว่าจอตายเมื่อเครื่องนั้นดับหรือเน็ตหลุด
- **เลิกใช้ API พิมพ์เองทั้งหมด** — ใช้ได้จริงแต่ทิ้งราคาทองแท่งที่อัตโนมัติได้ฟรี
- **thaigold.info (เลือกอันนี้)** — feed ที่เผยแพร่ให้เครื่องอ่าน แถว `สมาคมฯ` ตรงกับ
  goldtraders เป๊ะ (65,700 / 65,900 เมื่อ 2026-07-22) และ Vercel เข้าถึงได้จริง

feed นี้ไม่มีราคาทองรูปพรรณ วันเดียวกัน goldtraders ประกาศรูปพรรณขายออก 66,700
= ทองแท่ง 65,900 + 800 ส่วนซื้อเข้า 64,384.52 ไม่ใช่ส่วนต่างที่เดาได้

## Decision

ทองคำแท่งดึงจาก `thaigold.info/RealTimeDataV2/gtdata_.txt` แถว `สมาคมฯ`

ทองรูปพรรณเป็นราคาที่พนักงานกรอกเองเสมอ ไม่มีโหมด `api` ให้เลือกอีกต่อไป
`goldOrnamentMode` ถูกถอดออกจาก store และปุ่มสลับถูกถอดออกจากหน้า Dashboard

จอไม่แสดงเวลาอัปเดตอีกต่อไป

## Consequences

**ไม่มีสูตรราคาในโค้ด** ค่ากำเหน็จเป็นเรื่องที่แต่ละร้านกำหนดเอง และสูตรที่สมาคมใช้คำนวณ
ราคารับซื้อรูปพรรณก็ไม่ใช่ส่วนต่างคงที่ ถ้า hardcode ไว้แล้ววันหนึ่งมันเปลี่ยน จอจะแสดงราคาผิด
เงียบๆ โดยไม่มีอะไรฟ้อง — บนป้ายราคาหน้าร้านนั่นคือความผิดพลาดที่แพงที่สุดที่เป็นไปได้
แลกกับการที่พนักงานต้องพิมพ์ราคารูปพรรณเอง

**จอไม่มีเวลาอัปเดต** feed มีแต่นาฬิกา refresh ของตัวเอง ไม่ใช่เวลาที่สมาคมประกาศราคา
การเอาเลขนั้นมาแปะใต้คำว่า "อัปเดต" คือการบอกลูกค้าว่าราคานี้สดกว่าความจริง
ถ้าต้องการตัวบ่งชี้ว่าจอยังไม่ค้าง ควรใช้คำที่ตรงกว่า เช่น "ดึงข้อมูลล่าสุด"

**ผูกกับ feed เจ้าเดียว** ไม่มี fallback แล้ว ถ้า thaigold.info ล่ม `apiStatus` เป็น `offline`
และทองแท่งตกลง manual เหมือนรูปพรรณ ซึ่งเป็นพฤติกรรมที่มีอยู่แล้วและร้านใช้งานได้

**ราคาที่ค้างอยู่เป็นอันตรายกว่าที่คิด** ตอน API ตาย จอตกไป manual แล้วแสดงค่า default ที่
hardcode ไว้ตั้งแต่ 2026-05 (44,300) ขณะที่ราคาจริงคือ 65,900 ต่างกันสองหมื่นบาท
โดยไม่มีอะไรบนจอบอกว่าราคานี้เก่า — ควรมีตัวบ่งชี้ความเก่าของราคา manual ใน phase B
